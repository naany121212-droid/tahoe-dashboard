# تطبيق سيارتي لشاشة تاهو

هذا المشروع يغلّف لوحة القيادة في تطبيق Android أفقي بملء الشاشة. يسمح إذن الموقع عند الطلب لتشغيل عداد GPS والطقس ومواقيت الصلاة. تُضمَّن صور الخلفية داخل صفحة اللوحة، وتعمل الواجهة الأساسية دون اتصال؛ الخدمات الخارجية والخرائط تحتاج الإنترنت.

## البناء والتنزيل
عند دفع التغييرات إلى الفرع main، ينشئ GitHub Actions ملف APK تجريبيًا موقّعًا للتثبيت ويرفعه إلى GitHub Releases. استخدم أحدث إصدار ونزّل app-debug.apk. في جهاز السيارة اسمح بتثبيت التطبيقات من هذا المصدر عند الطلب.

التطبيق يضم صفحة الواجهة والخلفية الترحيبية كأصول محلية. أزرار RADARBOT وثمانية/ثمانية تُفتح إذا كانت التطبيقات مثبتة؛ وإلا يحاول التطبيق فتح صفحة المتجر المتاحة.
